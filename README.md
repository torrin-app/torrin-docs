# Torrin Docs

Documentation for [Torrin](https://github.com/torrin-app/torrin) — the
self-hostable debrid + streaming service. Built with [Mintlify](https://mintlify.com).

## Preview locally

```bash
mint dev
```

Serves a live, hot-reloading preview at http://localhost:3000.

## Structure

- `docs.json` — site config + navigation
- `*.mdx` — one file per page
